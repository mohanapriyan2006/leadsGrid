# Company Pages Feature

## Overview
Public-facing About and Contact pages for LeadsGrid. These pages communicate product positioning,
values, and direct contact paths for sales and support.

## Components
- `AboutHero`
- `AboutStory`
- `AboutValues`
- `FounderCard`
- `ContactHero`
- `ContactOptions`

## Pages
- `/about`
- `/contact`

## Behavior
- Static content only.
- Uses `PublicPageShell` for shared navigation and footer.

## Future Improvements
- Add a contact form that integrates with a backend service.
- Add a media kit section and press inquiries.
